- **Length / format:** 43.2 s (18 bars at 100 BPM), 30 fps, H.264 + AAC. Master 1920x1080; variants 1080x1350, 1080x1080, 1080x1920.
- **Content:** `../content.json` v1 only, via `assets/content.js` generated by `../tools/build-assets.mjs`. No number or sentence typed into a composition.
- **Design language:** `site/shared/current.css` tokens (`--cur-*`, `--src-*`, `--ser-*`), copied unchanged into `assets/current-tokens.css` by the build step. Inter (bundled `@font-face` file in `assets/fonts/`). Monochrome: series 1 bright solid, series 2 slate dashed; identity never by tone alone (line style + direct labels).

- **Metaphor:** the two-currents chart is a transparent fish skeleton in a pitch-dark ocean (spine = centreline, ribs = yearly threads, rib tips = endpoints). Between insights it folds, swims to the bottom left and morphs into the next chart (spine → lines, ribs → bars) while the copy scrolls up like a page. Continuous motion: breathing pulse on the rib tips and a spine sway ≤ 2 px during holds; the full undulation only in transitions. Data stays true: charts are read only from still, true-scale frames.
- **Motion (numbers):** chart draws 1.8–2.4 s with ease-in-out cubic; numbers appear with their copy (no count-up, so nothing changes while read); copy fades in 0.5 s with a 24 px rise then holds still; transitions: 1.8 s fold-swim-morph (fold 0.5 s, swim 0.9 s ease-in-out, morph 0.9 s overlapping), copy scroll 0.9 s ease-in-out in the same window; holds ≥ 3.5 s on every finished chart.
- **Cover:** frame 0 is beat 1 fully composed (title, chart, 13,507 / 18,418 labels). The opening sweep starts and ends on that frame.
- **Safe areas:** title and key number inside x/y 15–85% in every format and inside the centre 3:4 crop for 4:5; captions none.
- **Sound:** a soft piano bed (AngeloRizzo, "Relaxing piano", CC0; assets/bgm/CREDITS.md), faded in and resolving under the end card; quiet effects (a soft whoosh on each fold, a tick at the crossover), 3–6 dB over the bed; bed about −19 LUFS, true peak ≤ −2 dBTP.
- **QA:** `npm run check` after every composition edit; `npx hyperframes snapshot` at each beat in every format; cover frames checked with signalstats (YMAX − YMIN ≥ 40) and the 3:4 / 15–85% overlays.
